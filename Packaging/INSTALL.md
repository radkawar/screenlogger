# Install Screenlogger

This archive accompanies the Screenlogger DMG.
Screenlogger requires macOS 14 or later.
Public releases use Developer ID signatures and Apple notarization.
Local engineering builds can instead use ad-hoc signatures.

1. Open the DMG.
2. Drag Screenlogger to Applications.
3. Open the installed copy.
4. Complete Setup.
   Screenlogger requires Screen Recording and Accessibility.
5. Choose Start Capture.

App replacement or removal does not delete the Library.

## Optional Terminal command

Install `screenlog` from Screenlogger Settings under Integrations.
The technical ZIP also includes a `CLI` directory.
Keep its executable, framework, and skill directory together.
The command uses relative runtime paths.

## Verify the download

GitHub Releases includes `.sha256` files and a JSON manifest beside each DMG and ZIP.
Verify the checksum before installation.
Automatic update checks are off by default.
