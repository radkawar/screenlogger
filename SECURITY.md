# Security Policy

Screenlogger stores screenshots and recognized text.
Report security defects that can expose or corrupt a Library.
Also report defects that can increase Library access without the user's knowledge.

## Reporting a vulnerability

Do not open a public issue for a possible security defect.
Use GitHub's private security advisory form for this repository:

1. Open the repository's Security tab.
2. Choose Advisories.
3. Choose Report a vulnerability.

Include affected versions, reproduction steps, and expected effects.
Remove private content from logs before you attach them.
Do not attach a real Screenlogger Library or captured screenshots.

## Supported versions

Until the first stable release, Screenlogger supports only the newest prerelease.
A security fix can require a newer build.
It can also require you to grant macOS permissions again.
